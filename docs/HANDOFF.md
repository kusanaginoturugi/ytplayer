# 引き継ぎ

## 現在の状態

- 起動: `./ytplayer`
- 音声保存先: `~/Music/ytplayer/`
- 保存先変更: `YTPLAYER_MUSIC_DIR=/path/to/music ./ytplayer`
- 保存済みの音声は動画IDを含む名前で識別する。
- 次曲はバックグラウンドで準備し、未選択時は検索候補の2番目を仮予約する。

## 注意点

- ダウンロード失敗時は再生を止めず、ストリーミングへフォールバックする。
- mpv が次曲をプレイリストへ追加できた場合はギャップレス再生になる。次曲の準備が曲終端までに終わらなければ、完了後に再生を始める。
- リポジトリには既存の `__pycache__` 追跡ファイルがあり、今回生成されたバイトコード差分はコミットしない。
